Цей репозиторій містить повний набір матеріалів, розроблених у ході виконання лабораторних робіт з дисципліни **"Безпека програм та даних"**.

###  Про репозиторій
Проект створено для систематизації отриманих знань, зберігання вихідного коду рішень та відстеження прогресу навчання. Тут зібрано реалізації алгоритмів шифрування, методи стеганографії та скрипти автоматизації захисту.

### Структура проекту
Репозиторій організовано за модульним принципом. Кожна лабораторна робота розміщена в окремій директорії (`labXX`), яка містить:
*  **README.md** — детальне пояснення завдання та інструкція із запуску;
*  **Вихідний код** — скрипти та програми (Python);
*  **Результати** — скріншоти роботи програм, звіти та аналітика.
